## Descripción del sistema
La Panadería "El Sol" es un microemprendimiento privado que elabora y vende productos de panificación y pastelería.
El sistema propuesto es un módulo de software de **inventario y control de stock**. Permite:
- Registrar insumos, y sus entradas y salidas.
- Controlar las cantidades disponibles.
- Detectar cuándo es necesario reponer o cuándo un insumo está por vencer.

## Indicadores de control

Estos indicadores sirven para comprobar que el sistema de control de stock funciona bien. Las metas son valores iniciales y se pueden cambiar según cómo vaya funcionando la panadería.

### 1. Exactitud del inventario
- **Qué controla:** que lo que dice el sistema sea igual a lo que realmente hay en el depósito.
- **Meta:** 95 de cada 100 insumos con el stock correcto.
- **Cuándo se mide:** una vez por semana, contando los insumos a mano.

### 2. Faltantes de insumos
- **Qué controla:** que no falte ningún insumo para producir. Es el objetivo principal del sistema.
- **Meta:** 0 faltantes por mes.
- **Cuándo se mide:** una vez por mes.

### 3. Pérdidas por vencimiento
- **Qué controla:** que no se tire mercadería vencida, evitando pérdidas económicas por descarte de mercadería vencida.
- **Meta:** menos del 2 % de lo que se compra.
- **Cuándo se mide:** una vez por mes.
